# memes — «θαυμασμός από το βάθος»

Ο άντρας της `in/img2.jpg` μπαίνει στο βάθος της `in/img1.jpg`, πίσω από το μηχάνημα,
με τα χέρια ακουμπισμένα στη μπάρα, να κοιτάει την κοπέλα.

## Παραδοτέα

```
memes/out/woman_admired.png        903×1385  χωρίς το UI του story
memes/out/woman_admired_story.png  903×1601  όπως το screenshot
```

## Πώς ξαναφτιάχνεται

```powershell
cd D:\projects\news_feed
python memes\composite.py `
  --scale 0.47 --cut-y 950 --cx 512 --bottom 900 `
  --ct 1.0 --ct-ref scene --l-gain 0.96 --contrast 1.06 `
  --desat 0.70 --tint "1.04,1.0,0.93" --colorgain 0 `
  --rim 0.10 --vgrad 0.08 --shadow 0.55 --occl 60 --occl-from 0.75 `
  --out memes\out\woman_admired.png --clean
```

## Παλέτα (color match)

Το `--ct` κάνει **Reinhard color transfer σε CIELAB**: μεταφέρει το mean/std κάθε
καναλιού (L, a, b) από το φόντο της φωτογραφίας πάνω στον άντρα.

| Παράμετρος | Τι κάνει |
|---|---|
| `--ct 0..1` | πόσο δυνατά εφαρμόζεται η παλέτα (1.0 = πλήρης) |
| `--ct-ref scene` | αναφορά = όλο το κάδρο (η ζεστή, ελαιώδης ατμόσφαιρα του reel) |
| `--ct-ref local` | αναφορά = μόνο ό,τι είναι γύρω του (πιο «ουδέτερο») |
| `--ct-ref mix` | μισό-μισό |
| `--l-gain` | σκουραίνει/ανοίγει μετά το transfer (0.96 = λίγο πιο σκοτεινός, σωστό για βάθος) |
| `--desat` | κρατάει λίγη από τη χρωματική «βρωμιά» της σκηνής (0.7 = 30% desaturate) |
| `--tint` | μικρο-διόρθωση RGB πάνω από την παλέτα |

Χωρίς παλέτα (παλιά συμπεριφορά): βάλε `--ct 0` και ρύθμισε `--brightness/--tint`.

## Τι κάνει το `composite.py`

| Στάδιο | Τι συμβαίνει |
|---|---|
| `rembg` (u2net) | cut-out του άντρα· μεγαλύτερη συνιστώσα, fill holes, erode 1px, feather 1.2 |
| `--cut-y` | οριζόντιο κόψιμο στο ύψος των καρπών → το σώμα τελειώνει **πάνω** στη μπάρα |
| `--scale/--cx/--bottom` | κλίμακα, κέντρο, γραμμή επαφής |
| `--ct*` | παλέτα (βλ. πάνω) |
| `--blur/--grain` | βάθος πεδίου + κόκκος του reel |
| `--rim/--vgrad` | σκούρο περίγραμμα σιλουέτας + φως από πάνω (σπάει το «αυτοκόλλητο») |
| `--occl` | ό,τι είναι πιο σκούρο από το κατώφλι στο αρχικό κάδρο ξαναζωγραφίζεται μπροστά του → η μπάρα/τροχός τον κόβουν φυσικά |
| `--shadow` | σκιά επαφής κάτω από τα χέρια |
| `--clean` | κόβει το πάνω/κάτω UI του story |

## Tweaks

- Πιο διακριτικός: `--scale 0.40 --blur 1.2 --l-gain 0.92`
- Πιο εμφανής / πιο αστείος: `--scale 0.60 --cx 540 --bottom 905`
- Πιο «ουδέτερος» (λιγότερο ζεστός): `--ct-ref local --desat 1.0`
- Δεξιά αντί αριστερά: πρόσθεσε `--flip`
