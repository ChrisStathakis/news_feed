# Εγκατάσταση

## Βήμα 1 — Εγκατάσταση

1. Άνοιξε το αρχείο **`Hmerisia-Setup-1.0.0.exe`**.
2. Αν τα Windows δείξουν μπλε παράθυρο **«Windows προστάτευσε τον υπολογιστή σας»**,
   πάτησε **«Περισσότερες πληροφορίες» → «Εκτέλεση ούτως ή άλλως»**.
   (Εμφανίζεται επειδή η εφαρμογή δεν έχει ψηφιακή υπογραφή — δεν είναι ιός.)
3. Διάλεξε φάκελο εγκατάστασης (η προεπιλογή είναι καλή) και πάτησε **Εγκατάσταση**.
4. Στο τέλος θα δημιουργηθεί συντόμευση **«Η ΗΜΕΡΗΣΙΑ»** στην Επιφάνεια εργασίας και στο μενού Έναρξη.

!!! info "Δεν χρειάζεται Python"
    Η εφαρμογή και η μηχανή σύνταξης της εφημερίδας είναι **ενσωματωμένες**
    στο ίδιο πακέτο. Δεν εγκαθιστάς τίποτα άλλο.

## Βήμα 2 — Πρώτη εκκίνηση

Με το πρώτο άνοιγμα θα δεις την οθόνη **«Σημερινό φύλλο»** με το μήνυμα
*«Δεν υπάρχει φύλλο για σήμερα»*. Είναι φυσιολογικό.

Πάτησε **«Νέο φύλλο»** και περίμενε να ολοκληρωθεί η σύνταξη.
Μετά το πρώτο φύλλο, η εφαρμογή ανοίγει πάντα με το τελευταίο φύλλο έτοιμο.

!!! warning "Χρειάζεσαι internet"
    Χωρίς σύνδεση το φύλλο θα βγει με ελάχιστα ή καθόλου θέματα.
    Οι εικόνες και τα άρθρα κατεβαίνουν την ώρα της σύνταξης.

## Πού κρατάει τα δεδομένα της

Όλα τα αρχεία βρίσκονται σε **έναν** φάκελο:

```
%APPDATA%\hmerisia-desktop\
├─ output\        ← τα φύλλα (HTML + PDF)
├─ cache\         ← προσωρινές εικόνες/άρθρα
├─ settings.json  ← ρυθμίσεις
├─ sites.txt      ← οι πηγές σου
├─ health.json    ← κατάσταση πηγών
└─ ui.json        ← zoom, θέμα, τελευταία προβολή
```

Για να τον ανοίξεις: πάτησε <kbd>Win</kbd>+<kbd>R</kbd>, γράψε `%APPDATA%\hmerisia-desktop` και πάτησε Enter.

!!! tip "Αντίγραφο ασφαλείας"
    Αντέγραψε ολόκληρο τον φάκελο `hmerisia-desktop` σε ένα USB.
    Για επαναφορά, αντικατέστησέ τον στον ίδιο δρόμο με την εφαρμογή κλειστή.

## Ενημέρωση

Κατέβασε το νεότερο `Hmerisia-Setup-x.x.x.exe` και τρέξ' το πάνω από την παλιά έκδοση.
Οι ρυθμίσεις, οι πηγές και τα φύλλα **δεν χάνονται**.

## Απεγκατάσταση

**Ρυθμίσεις Windows → Εφαρμογές → Εγκατεστημένες εφαρμογές → Η ΗΜΕΡΗΣΙΑ → Κατάργηση**.
Αν θέλεις να σβηστούν και τα φύλλα, διάγραψε χειροκίνητα τον φάκελο
`%APPDATA%\hmerisia-desktop` μετά την απεγκατάσταση.
