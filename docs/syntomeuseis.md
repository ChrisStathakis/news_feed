# Συντομεύσεις

## Πληκτρολόγιο

| Πλήκτρο | Τι κάνει |
|---|---|
| <kbd>F11</kbd> | Πλήρης οθόνη / έξοδος |
| <kbd>Esc</kbd> | Έξοδος από πλήρη οθόνη |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Εκτύπωση (ανοίγει προεπισκόπηση PDF) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Αντιγραφή URL του άρθρου που διαβάζεις |

## Κουμπιά της πάνω μπάρας

| Κουμπί | Τι κάνει |
|---|---|
| **← Πίσω** | Επιστροφή στο φύλλο, στην ίδια θέση ανάγνωσης. |
| **⌂ Φύλλο** | Επιστροφή στο φύλλο από οπουδήποτε. |
| **− / Fit / +** | Σμίκρυνση, προσαρμογή, μεγέθυνση. Απομνημονεύεται. |
| **🔗 URL** | Αντιγραφή συνδέσμου (εμφανίζεται μόνο μέσα σε άρθρο). |
| **Εκτύπωση** | Δημιουργεί PDF και ανοίγει προεπισκόπηση. |
| **PDF** | Δημιουργεί PDF απευθείας στον φάκελο PDF. |
| **Browser** | Ανοίγει το φύλλο στον προεπιλεγμένο browser. |
| **⛶ Full** | Πλήρης οθόνη. |
| **Νέο φύλλο** | Ξεκινά νέα σύνταξη. |

## Μπάρα πλήρους οθόνης

Εμφανίζεται με κίνηση του κέρσορα στο πάνω μέρος και περιέχει:
**← Πίσω**, **⌂ Φύλλο**, όνομα site, **− / Fit / +**, **🔗**, **Εκτύπωση**, **✕**.

## Κατά την έκδοση

| Κουμπί | Τι κάνει |
|---|---|
| **■ Στοπ** | Σταματά αμέσως την έκδοση (και την προγραμματισμένη). |
| **Νέο φύλλο** | Ξεκινά νέα έκδοση όταν δεν τρέχει καμία. |

## Ποντίκι

| Ενέργεια | Αποτέλεσμα |
|---|---|
| Τροχός | Κύλιση στο φύλλο. |
| Κλικ σε τίτλο | Άνοιγμα άρθρου μέσα στην εφαρμογή. |
| Κλικ σε **«Άνοιξε το άρθρο»** | Άνοιγμα της πηγής. |
| Κλικ σε **«← Πίσω»** | Επιστροφή στη θέση που διάβαζες. |
